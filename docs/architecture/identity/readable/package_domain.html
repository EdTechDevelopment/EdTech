identity.domain
Исходная спецификация VP

Назначение пакета

Центральная бизнес-модель модуля Identity.

Содержит сущности, value object, перечисления, бизнес-правила, допустимые изменения состояния, доменные события и доменные исключения.

Domain является чистым Java-кодом и не зависит от Spring, HTTP, jOOQ, PostgreSQL, SMTP и Spring Session.

user
identity.domain.user
Определяет границу агрегата User и объединяет связанные с ним доменные объекты, события и исключения. Агрегат отвечает за состояние аккаунта пользователя, подтверждение текущего email, изменение email, обновление имени, назначенные роли и допустимые переходы статуса. Все изменения состояния аккаунта выполняются через корень агрегата User. Внешний код не должен изменять отдельные поля или вложенные объекты напрямую.

verification
identity.domain.verification
Определяет агрегат EmailVerification и связанные с ним доменные типы. Агрегат управляет жизненным циклом одноразового подтверждения email: хранит только хэш токена, назначение подтверждения, целевой адрес, срок действия, время использования и время аннулирования. EmailVerification ссылается на агрегат User только через userId и не получает объектную или ORM-связь с User. Изменение User после проверки токена координируется application-сервисом.
