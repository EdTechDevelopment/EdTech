Назначение пакета

Объединяет HTTP-модели сценариев регистрации и аутентификации.

Модели этого пакета описывают данные, которыми обмениваются frontend

и backend. Они не являются доменными сущностями, application-командами

или структурами хранения данных.

Полный состав полей, обязательность, форматы и ограничения моделей

определяются OpenAPI-контрактом.

request
identity.presentation.auth.model.request
Содержит модели входящих HTTP-запросов регистрации, входа, подтверждения email и повторной отправки письма. Request-модели отражают структуру входящего JSON и содержат только данные, которые клиент имеет право передавать. В request-моделях разрешается указывать аннотации структурной валидации: обязательность поля, длину строки и формат email. Проверка уникальности email, состояния пользователя, правильности пароля и действительности токена не относится к этому пакету.

response
identity.presentation.auth.model.response
Содержит HTTP-ответы сценариев регистрации, подтверждения email, входа и обновления токенов. Response-модели содержат только данные, разрешённые для frontend. Они не должны раскрывать passwordHash, проверочные токены, внутреннее состояние refresh-сессии и другие технические данные Identity. Полный формат JSON определяется OpenAPI-контрактом.
