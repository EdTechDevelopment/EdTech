Назначение пакета

Группа HTTP-сценариев работы с общими данными текущего аккаунта.

Пакет обслуживает изменение имени, фамилии и email пользователя.

Текущий пользователь определяется по подтверждённому access JWT,

а не по userId, переданному frontend.

Изменение имени и фамилии выполняется сразу. Изменение email запускает

процесс подтверждения нового адреса через pendingEmail.

TeacherProfile, StudentProfile, предметы и расписание не принадлежат

этому пакету.

controller
identity.presentation.account.controller
Содержит REST-контроллеры операций текущего аккаунта. Контроллер получает идентификатор текущего пользователя из контекста Spring Security, преобразует HTTP-запрос в application-команду и вызывает входной application-порт. Контроллер не должен принимать идентификатор изменяемого пользователя из request body или path parameter.

mapper
identity.presentation.account.mapper
Содержит преобразования HTTP-моделей account в модели application и обратно. Mapper добавляет в application-команду userId, полученный контроллером из подтверждённого JWT, и переносит изменяемые данные из request. Пакет не выполняет проверку уникальности email, не загружает User и не применяет к нему изменения.
