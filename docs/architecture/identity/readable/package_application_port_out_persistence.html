Назначение пакета

Содержит абстракции сохранения и поиска доменных объектов User, EmailVerification и внутреннего состояния refresh token.

Интерфейсы не содержат jOOQ records, SQL и деталей PostgreSQL.

EmailVerificationRepository
Класс
Выходной порт хранения aggregate EmailVerification. Позволяет найти проверку по hash токена, найти активную проверку пользователя определённого назначения и сохранить изменённое состояние. Интерфейс не содержит jOOQ records и SQL.

RefreshTokenRepository
Класс
Выходной порт хранения состояния refresh token. Хранит только hash токена и служебное состояние. Поддерживает сохранение, отзыв, ротацию и отзыв всей token family. Конкретная реализация через PostgreSQL и jOOQ находится в infrastructure.

UserRepository
Класс
Выходной порт хранения aggregate User. Предоставляет application только доменные объекты и не раскрывает SQL, jOOQ records или структуру таблиц. Проверка existsByEmailOrPendingEmail учитывает основной и ожидающий подтверждения email.
