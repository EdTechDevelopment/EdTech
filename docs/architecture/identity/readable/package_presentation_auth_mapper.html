Исходная спецификация VP

Назначение пакета

Содержит преобразования между HTTP-моделями auth и моделями application.

Mapper преобразует request DTO в application command и application

result в response DTO. Преобразование должно быть детерминированным

и не иметь внешних побочных эффектов.

Mapper не обращается к repository, базе данных, JWT-провайдеру,

SMTP и другим backend-модулям. Он не проверяет бизнес-правила

и не управляет транзакциями.
