Назначение пакета

Содержит REST-контроллеры сценариев регистрации и аутентификации.

Контроллеры определяют URL, HTTP-метод, ожидаемый request и возвращаемый

response. Они извлекают данные из JSON, заголовков и cookie, после чего

передают выполнение входному application-порту.

Контроллер может выбрать HTTP-статус, установить или удалить cookie

и передать результат mapper-классу.

Контроллер не должен содержать SQL, транзакции, бизнес-проверки,

криптографические операции, генерацию токенов или непосредственные

вызовы infrastructure.

AuthController
Класс
HTTP-точка входа для регистрации, входа, обновления JWT и выхода. При регистрации контроллер принимает RegisterRequest и вызывает RegisterUserUseCase. В ответ возвращает информацию о необходимости подтверждения email. При входе контроллер вызывает LoginUseCase. Access token возвращается в теле HTTP-ответа, а refresh token устанавливается в HttpOnly cookie. При обновлении токенов контроллер получает refresh token из cookie и передаёт его RefreshTokenUseCase. При выходе контроллер передаёт refresh token LogoutUseCase и удаляет refresh cookie из браузера.

EmailVerificationController
Класс
HTTP-точка входа для подтверждения email и повторной отправки письма подтверждения. Контроллер принимает одноразовый открытый токен, передаёт его ConfirmEmailUseCase и возвращает результат аутентификации после успешной активации пользователя. При повторной отправке контроллер передаёт email в ResendEmailVerificationUseCase. Ответ не должен раскрывать, существует ли пользователь с указанным email.
