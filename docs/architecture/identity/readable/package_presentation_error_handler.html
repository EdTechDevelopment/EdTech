IdentityExceptionHandler
Класс
Преобразует ошибки HTTP-валидации и application-сценариев Identity в единый ApiError. Обрабатывает неверные учётные данные, неподтверждённый email, конфликт email, неверный проверочный токен, неверный refresh token, отсутствие авторизации и недопустимое состояние аккаунта. Не содержит бизнес-логику и только отображает уже определённую ошибку в HTTP.

RestAccessDeniedHandler
Класс
Формирует единый ApiError при недостаточных правах аутентифицированного пользователя. Возвращает HTTP 403 и ErrorCode.FORBIDDEN. Обработчик не изменяет правила авторизации.
›
◇
RestAuthenticationEntryPoint
Класс
Формирует единый ApiError для запроса без корректной аутентификации. Возвращает HTTP 401 и ErrorCode.UNAUTHENTICATED. Обработчик не проверяет JWT самостоятельно и не содержит бизнес-логику.
