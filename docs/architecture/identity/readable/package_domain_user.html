Назначение пакета

Определяет границу агрегата User и объединяет связанные с ним доменные объекты, события и исключения. Агрегат отвечает за состояние аккаунта пользователя, подтверждение текущего email, изменение email, обновление имени, назначенные роли и допустимые переходы статуса.

Все изменения состояния аккаунта выполняются через корень агрегата User. Внешний код не должен изменять отдельные поля или вложенные объекты напрямую.

event
identity.domain.user.event
Фиксирует факт успешного создания агрегата User. В момент возникновения пользователь имеет статус PENDING_EMAIL_VERIFICATION и ещё не может выполнять вход. Событие является внутренним для домена. Application-слой может преобразовать его в публичный UserRegisteredEvent и использовать для запуска разрешённых межмодульных сценариев.

exception
identity.domain.user.exception
Содержит исключения, возникающие при нарушении инвариантов агрегата User и принадлежащих ему объектов-значений. Исключения описывают доменную причину ошибки, но не содержат HTTP-статусы, API error codes, JSON-модели или сведения о persistence. Преобразование доменной ошибки в application-ошибку и HTTP-ответ выполняется во внешних слоях.

model
identity.domain.user.model
Содержит корень агрегата User, принадлежащие ему объекты-значения и перечисления. User является единственной точкой изменения состояния аккаунта и защищает его бизнес-инварианты. Пакет не выполняет поиск уникального email, проверку открытого пароля, создание JWT, сохранение в базу данных или отправку писем. Эти действия координируются application-слоем через выходные порты.
