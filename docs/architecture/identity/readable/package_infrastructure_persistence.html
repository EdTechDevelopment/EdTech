Исходная спецификация VP

Назначение пакета

Содержит реализацию хранения данных Identity через PostgreSQL и jOOQ.

Persistence преобразует доменные объекты и внутренние application-модели в записи базы данных. jOOQ records не выходят за границы этого пакета.

Преобразует UserPersistenceData в доменный aggregate User и обратно. Восстанавливает Email, pendingEmail, PasswordHash, UserRole и UserStatus. Не выполняет SQL и не проверяет прикладные правила. При сохранении создаёт отдельные записи CURRENT и PENDING для таблицы identity_user_emails.
