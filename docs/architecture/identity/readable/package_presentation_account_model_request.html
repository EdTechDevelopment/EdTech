UpdateCurrentUserRequest
Класс
Входная HTTP-модель частичного изменения текущего пользователя. Запрос должен содержать минимум одно изменяемое поле. Изменение email запускает двухэтапный процесс через pendingEmail. Роли, пароль и статус аккаунта через этот запрос не изменяются. Полный набор доступных полей определяется OpenAPI.
