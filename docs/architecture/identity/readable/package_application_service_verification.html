ConfirmEmailService
Класс
Реализация ConfirmEmailUseCase. Вычисляет hash полученного токена, загружает EmailVerification и проверяет возможность его использования. Для регистрации активирует User, а для изменения email подтверждает pendingEmail. После сохранения aggregate публикует соответствующее публичное событие, выпускает токены и возвращает AuthenticationResult. Сервис не вызывает LoginService и использует общие output ports аутентификации напрямую.

ResendEmailVerificationService
Класс
Реализация ResendEmailVerificationUseCase. Находит пользователя, инвалидирует предыдущую активную проверку, создаёт новый проверочный токен и инициирует отправку письма. Для неизвестного email и недоступной операции возвращает тот же внешний результат, чтобы не раскрывать наличие аккаунта.
