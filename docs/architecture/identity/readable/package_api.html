Назначение пакета

Публичный Java API модуля Identity для взаимодействия с другими backend-модулями.

Предоставляет безопасные сведения о пользователях: идентификатор, имя, фамилию, email, роли и статус аккаунта.

Tutoring и Scheduling обращаются к Identity только через этот пакет. Внутренние доменные сущности, пароль, сессии и проверочные токены через API не раскрываются.

event
identity.api.event
Публичное событие регистрации пользователя. Публикуется после успешного сохранения нового аккаунта. Tutoring обрабатывает событие, чтобы найти ожидающее приглашение по email и связать его с зарегистрированным userId. Приглашение остаётся в статусе PENDING до явного принятия учеником.

identity.api.model
Безопасное неизменяемое представление пользователя для межмодульного взаимодействия. Содержит идентификатор, подтверждённый email, имя, фамилию, роли и состояние аккаунта. Не содержит passwordHash, pendingEmail, JWT, refresh-токены, проверочные токены и persistence records.

identity.api.query
Публичный синхронный интерфейс чтения данных пользователей. Используется модулями Tutoring и Scheduling для получения безопасного представления пользователя и проверки его ролей. Интерфейс не изменяет состояние Identity и не возвращает внутренние доменные сущности.
