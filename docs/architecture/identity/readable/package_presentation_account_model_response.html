Назначение пакета

Содержит HTTP-представление данных аккаунта пользователя.

Response-модели предназначены для frontend и содержат только разрешённые

данные. В них отсутствуют пароль, passwordHash, открытые проверочные

токены, refresh token и внутренние сведения безопасности.
