ConfirmEmailUseCase
Класс
Входной порт подтверждения email по одноразовому токену. Подтверждает регистрацию пользователя или изменение email в зависимости от назначения найденного EmailVerification. После успешного подтверждения выпускает access JWT и refresh token и возвращает AuthenticationResult.

◇
ResendEmailVerificationUseCase
Класс
Входной порт повторной отправки письма подтверждения email. Предыдущая активная проверка инвалидируется, после чего создаётся новый одноразовый токен. Результат сценария не должен раскрывать, существует ли пользователь с переданным email.
