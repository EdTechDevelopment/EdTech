LoginUseCase
Класс
Входной порт аутентификации пользователя по email и паролю. Проверяет учётные данные и возможность пользователя проходить аутентификацию. После успешной проверки выпускает access JWT и refresh token.
›
◇
LogoutUseCase
Класс
Входной порт выхода пользователя. Отзывает refresh token, переданный presentation из HttpOnly cookie. Операция является идемпотентной и не раскрывает, существовал ли переданный токен.
›
◇
RefreshTokenUseCase
Класс
Входной порт обновления токенов аутентификации. Проверяет полученный refresh token, выполняет его ротацию и возвращает новый access JWT и новый refresh token. Повторное использование отозванного refresh token приводит к отзыву связанной token family.
