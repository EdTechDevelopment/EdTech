Назначение пакета

Безопасное неизменяемое представление пользователя для межмодульного взаимодействия.

Содержит идентификатор, подтверждённый email, имя, фамилию, роли и состояние аккаунта.

Не содержит passwordHash, pendingEmail, JWT, refresh-токены, проверочные токены и persistence records.

UserStatusView
Класс
Публичное представление состояния аккаунта. PENDING_EMAIL_VERIFICATION означает, что пользователь зарегистрирован, но ещё не подтвердил email. ACTIVE означает, что пользователь подтвердил email и может проходить аутентификацию. BLOCKED означает, что доступ пользователя заблокирован.
