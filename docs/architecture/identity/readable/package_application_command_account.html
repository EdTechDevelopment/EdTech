RegisterUserCommand
Класс
Неизменяемая входная модель регистрации пользователя. Содержит открытый пароль только на время выполнения сценария. Открытый пароль нельзя сохранять, возвращать в ответе или записывать в журнал.

UpdateCurrentUserCommand
Класс
Неизменяемая входная модель частичного изменения текущего пользователя. userId определяется по аутентифицированному principal и не принимается от клиента. Команда должна содержать минимум одно изменяемое поле. В Java может быть реализована как record.
