identity.presentation.auth.model.response
Исходная спецификация VP

Назначение пакета

Содержит HTTP-ответы сценариев регистрации, подтверждения email,

входа и обновления токенов.

Response-модели содержат только данные, разрешённые для frontend.

Они не должны раскрывать passwordHash, проверочные токены, внутреннее

состояние refresh-сессии и другие технические данные Identity.

Полный формат JSON определяется OpenAPI-контрактом.

TokenResponse
Класс
HTTP-ответ успешной аутентификации или обновления токенов. Содержит access JWT, тип авторизации Bearer и информацию о сроке действия access token. Refresh token в эту модель не входит и передаётся только через HttpOnly cookie.

VerificationPendingResponse
Класс
HTTP-ответ успешной регистрации неподтверждённого пользователя. Сообщает frontend, что аккаунт создан и ожидает подтверждения email. Может содержать email и время окончания действия отправленного проверочного токена.
