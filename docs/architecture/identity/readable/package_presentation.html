Исходная спецификация VP

Назначение пакета

Внешний HTTP-интерфейс модуля Identity для frontend.

Принимает HTTP-запросы и JSON, выполняет структурную валидацию входных данных, преобразует request DTO в application-команды, вызывает input-порты и формирует HTTP-ответы.

Также преобразует исключения application и domain в единый формат ApiError.

auth
identity.presentation.auth
Группа HTTP-сценариев, связанных с регистрацией и аутентификацией пользователя. Пакет обслуживает регистрацию, подтверждение email, повторную отправку письма подтверждения, вход, обновление токенов и выход. Auth отвечает только за HTTP-представление этих сценариев. Он принимает учётные данные и токены от клиента, передаёт их application use cases и формирует соответствующий HTTP-ответ. Пакет не сравнивает пароль с хэшем, не создаёт JWT, не проверяет подпись JWT, не сохраняет refresh token и не загружает пользователя из базы данных.
