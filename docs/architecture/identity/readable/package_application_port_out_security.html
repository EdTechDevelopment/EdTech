Назначение пакета

Содержит абстракции хеширования паролей, генерации проверочных токенов, выпуска JWT и управления значениями refresh token.

Конкретные алгоритмы и библиотеки выбираются в infrastructure.

Выходной порт выпуска короткоживущего access JWT. Получает идентификатор пользователя, его роли и время выпуска. Конкретный алгоритм подписи, набор claims и длительность токена определяются в infrastructure.

RefreshTokenHasher
Класс
Выходной порт вычисления hash полученного refresh token. Hash используется для поиска RefreshTokenState, поскольку открытое значение refresh token в базе данных не хранится.

RefreshTokenIssuer
Класс
Выходной порт выпуска refresh token. При отсутствии familyId создаёт новую token family. При ротации выпускает токен в существующей family. Возвращает открытое значение, hash, идентификаторы и срок действия токена.
