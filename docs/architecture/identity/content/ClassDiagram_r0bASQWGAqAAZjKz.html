  IntegrationEventPublisher : Class

Выходной порт публикации публичных событий Identity.

 

Получает события из identity.api.event после успешного изменения состояния. Другие бизнес-модули подписываются на эти события, не получая доступ к domain Identity.

  VerificationEmailSender : Class

Выходной порт отправки письма подтверждения email.

 

Application передаёт адрес получателя, открытый одноразовый токен, назначение проверки и срок действия.

 

Техническая доставка через notifications или SMTP-adapter реализуется в infrastructure.
