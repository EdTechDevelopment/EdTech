Model Elements
Name Description
  Email : Class

Неизменяемый объект-значение, представляющий нормализованный email пользователя. Проверяет обязательность значения, удаляет внешние пробелы и гарантирует допустимый формат адреса.

 

Сравнение объектов Email выполняется по значению. Объект не проверяет уникальность адреса в системе, поскольку такая проверка требует обращения к repository.

  InvalidVerificationException : Class

Возникает, когда EmailVerification невозможно использовать: срок действия истёк, подтверждение уже использовано или оно было аннулировано.

 

Application-слой преобразует такие случаи в единую внешнюю ошибку INVALID_VERIFICATION_TOKEN, чтобы не раскрывать технические подробности проверки токена.

  VerificationPurpose : Class

Определяет назначение подтверждения email. Назначение используется application-сервисом для выбора допустимой операции над агрегатом User после успешной проверки токена.

  VerificationTokenHash : Class

Неизменяемый объект-значение, представляющий хэш одноразового verification token. Открытый токен существует только на границе сценария и никогда не сохраняется внутри доменной модели или базы данных.

 

Объект не определяет конкретный алгоритм хэширования. Генерация и хэширование токена выполняются через выходные порты application-слоя.

  EmailVerification : Class

Корень агрегата подтверждения email. Представляет одно подтверждение первоначального адреса или изменения текущего адреса пользователя.

 

Агрегат хранит только хэш токена и запрещает повторное использование, использование после истечения срока действия и использование после аннулирования. Срок действия нового подтверждения составляет 24 часа.

 

EmailVerification не активирует User и не изменяет его email напрямую. После успешного использования подтверждения application-сервис загружает User по userId и вызывает соответствующую доменную операцию.
