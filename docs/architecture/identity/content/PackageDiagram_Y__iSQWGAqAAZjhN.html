Model Elements
Name Description
  repository : Package

Содержит низкоуровневые компоненты доступа к PostgreSQL через DSLContext.

 

Repository выполняет SQL и возвращает jOOQ records или persistence data. Он не зависит от domain и не реализует application output ports.

  generated : Package

Содержит классы таблиц, записей и перечислений, автоматически созданные jOOQ Codegen по актуальной Flyway-схеме.

 

Сгенерированные классы не редактируются вручную и используются только внутри infrastructure.persistence.

  model : Package

Содержит внутренние составные модели, необходимые для передачи результатов jOOQ-запросов между data repository и persistence mapper.

 

Эти модели не выходят из infrastructure.persistence.
