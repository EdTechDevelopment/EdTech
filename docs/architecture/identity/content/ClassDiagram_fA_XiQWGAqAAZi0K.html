Model Elements
Name Description
  AuthenticationResult : Class

Внутренний результат успешной аутентификации, подтверждения email или обновления токенов.

 

Presentation переносит access token и срок его действия в TokenResponse. Refresh token помещается в HttpOnly cookie и не включается в HTTP response body.

 

Result не должен передаваться другим бизнес-модулям.

  CurrentUserResult : Class

Безопасное application-представление текущего пользователя.

 

Используется как результат получения и изменения аккаунта. Не содержит passwordHash, refresh token, проверочные токены и persistence-модели.

 

Presentation преобразует его в UserResponse.

  ResendVerificationResult : Class

Унифицированный результат запроса повторной отправки письма подтверждения.

 

Результат возвращается в одинаковом виде независимо от существования пользователя. Это предотвращает определение зарегистрированных email через публичный endpoint.

  RegistrationResult : Class

Результат успешной регистрации пользователя.

 

Сообщает, что аккаунт создан и требует подтверждения email. Не содержит открытый пароль, passwordHash или проверочный токен.

 

Presentation преобразует этот результат в VerificationPendingResponse.
