Name Description
  UpdateCurrentUserUseCase : Class

Входной порт частичного изменения текущего пользователя.

 

Позволяет изменить имя, фамилию или запросить изменение email. Новый email становится pendingEmail и требует отдельного подтверждения.

 

Роли, пароль и статус аккаунта через этот сценарий не изменяются.

  GetCurrentUserUseCase : Class

Входной порт получения данных текущего авторизованного пользователя.

 

Идентификатор пользователя передаётся через GetCurrentUserQuery и должен быть получен presentation из подтверждённого SecurityContext.

 

Возвращает безопасную application-модель без passwordHash и токенов.

  RegisterUserUseCase : Class

Входной порт регистрации нового пользователя.

 

Создаёт аккаунт со статусом ожидания подтверждения email, сохраняет одноразовую проверку и инициирует отправку письма.

 

Регистрация не выдаёт токены аутентификации до подтверждения email. Реализация интерфейса находится в application.service.account.
