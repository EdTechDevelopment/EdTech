 LoginService : Class

Реализация LoginUseCase.

 

Находит User по email, проверяет пароль и вызывает доменную проверку возможности аутентификации.

 

После успешной проверки выпускает access JWT и refresh token, сохраняет RefreshTokenState и возвращает AuthenticationResult.

 RefreshTokenService : Class

Реализация RefreshTokenUseCase.

 

Вычисляет hash refresh token, загружает его состояние и проверяет срок действия и отсутствие отзыва.

 

Выпускает новый access JWT и новый refresh token в той же family. Старый токен отзывается и связывается с новым через replacedByTokenId.

 

Ротация старого токена и сохранение нового выполняются в одной транзакции.

 LogoutService : Class

Реализация LogoutUseCase.

 

Вычисляет hash переданного refresh token и отзывает найденное состояние токена.

 

Операция является идемпотентной: неизвестный или уже отозванный токен не приводит к раскрытию внутреннего состояния.
