Model Elements
Name Description
  UserRoleView : Class

Публичное представление ролей пользователя.

 

Отделено от внутреннего доменного перечисления identity.domain.model.UserRole.

 

Один пользователь может одновременно иметь роли TEACHER и STUDENT.

  UserAccountUpdatedEvent : Class

Публичное событие изменения общих данных аккаунта.

 

Публикуется после изменения имени, фамилии или подтверждённой смены email.

 

Может использоваться другими модулями для обновления локальной read model.

  UserActivatedEvent : Class

Публичное событие активации аккаунта.

 

Публикуется после успешного подтверждения email и перехода пользователя в состояние ACTIVE.

  UserRegisteredEvent : Class

Публичное событие регистрации пользователя.

 

Публикуется после успешного сохранения нового аккаунта.

 

Tutoring обрабатывает событие, чтобы найти ожидающее приглашение по email и связать его с зарегистрированным userId. Приглашение остаётся в статусе PENDING до явного принятия учеником.
