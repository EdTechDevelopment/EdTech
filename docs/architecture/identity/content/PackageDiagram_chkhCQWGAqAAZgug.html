Model Elements
Name Description
  validation : Package

Содержит проверки структуры HTTP-запросов account, которые нельзя выразить простой проверкой одного поля.

 

Проверки относятся только к форме входящего запроса. Пакет не проверяет состояние User, уникальность email и другие бизнес-правила.

  mapper : Package

Содержит преобразования HTTP-моделей account в модели application и обратно.

 

Mapper добавляет в application-команду userId, полученный контроллером из подтверждённого JWT, и переносит изменяемые данные из request.

 

Пакет не выполняет проверку уникальности email, не загружает User и не применяет к нему изменения.

  model : Package

Объединяет HTTP-модели операций текущего аккаунта.

 

Модели этого пакета описывают обмен данными между frontend и Identity.

Они не являются доменной сущностью User и не должны использоваться

как persistence-модели.

  controller : Package

Содержит REST-контроллеры операций текущего аккаунта.

 

Контроллер получает идентификатор текущего пользователя из контекста

Spring Security, преобразует HTTP-запрос в application-команду

и вызывает входной application-порт.

 

Контроллер не должен принимать идентификатор изменяемого пользователя

из request body или path parameter.
