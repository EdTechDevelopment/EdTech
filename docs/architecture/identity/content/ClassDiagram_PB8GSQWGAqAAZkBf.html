  NotificationVerificationEmailAdapter : Class

Преобразует запрос Identity в типизированную команду публичного API модуля Notifications.

 

Формирует confirmationUrl, преобразует VerificationPurpose во внешний VerificationEmailPurpose и вызывает NotificationGateway.enqueue.

 

Адаптер не использует SMTP, JavaMailSender и внутренние пакеты Notifications.

  IdentityNotificationProperties : Class

Содержит базовый frontend URL страницы подтверждения email.

 

NotificationVerificationEmailAdapter добавляет к URL безопасно закодированный verification token.

 

Значение отличается для local, test и production окружений.
