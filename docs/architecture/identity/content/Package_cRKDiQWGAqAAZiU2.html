Содержит внутренние модели application, необходимые для выпуска и хранения токенов.

Эти модели не передаются frontend и другим бизнес-модулям.

Children
Name Description
 IssuedAccessToken : Class

Внутренняя модель access JWT, созданного через AccessTokenIssuer.

 

Содержит готовое значение токена и момент окончания его срока действия.

 IssuedRefreshToken : Class

Внутренняя модель только что выпущенного refresh token.

 

Открытое значение передаётся presentation для установки HttpOnly cookie. Hash и служебные идентификаторы используются для создания RefreshTokenState и сохранения через RefreshTokenRepository.

 RefreshTokenState : Class

Внутренняя модель сохранённого состояния refresh token.

 

Используется для проверки срока действия, отзыва, ротации и обнаружения повторного использования токена.

 

Открытое значение refresh token в этой модели не хранится.
