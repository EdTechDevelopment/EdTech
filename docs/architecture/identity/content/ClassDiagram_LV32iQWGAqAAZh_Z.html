Model Elements
Name Description
  User : Class

Корень агрегата аккаунта пользователя. Хранит идентификатор, текущий и ожидающий подтверждения email, хэш пароля, имя, фамилию, роли, статус и временные метки.

 

User является единственной точкой изменения состояния аккаунта. Он проверяет наличие хотя бы одной роли, запрещает недопустимые переходы статуса, управляет двухэтапной сменой email и не позволяет аутентификацию до подтверждения адреса.

 

Класс не хранит открытый пароль, JWT, refresh token или технические данные persistence. Уникальность email проверяется application-сервисом через UserRepository.

  UserAccountUpdatedEvent : Class

Фиксирует факт успешного изменения данных аккаунта пользователя. Может возникать после изменения имени, фамилии или завершённой смены подтверждённого email.

 

Событие не содержит пароль, passwordHash, pendingEmail или данные токенов. Application-слой получает необходимый безопасный снимок User и преобразует событие в публичный UserAccountUpdatedEvent.

  UserActivatedDomainEvent : Class

Фиксирует факт активации аккаунта после успешного подтверждения первоначального email. Событие создаётся только после допустимого перехода пользователя из состояния PENDING_EMAIL_VERIFICATION в ACTIVE.

 

Application-слой может преобразовать событие в публичный UserActivatedEvent.

  UserRegisteredDomainEvent : Class

Фиксирует факт успешного создания агрегата User. В момент возникновения пользователь имеет статус PENDING_EMAIL_VERIFICATION и ещё не может выполнять вход.

 

Событие является внутренним для домена. Application-слой может преобразовать его в публичный UserRegisteredEvent и использовать для запуска разрешённых межмодульных сценариев.
