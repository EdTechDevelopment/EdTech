  IdentityApiMapper : Class

Преобразует внутренние доменные объекты и domain events в публичные модели identity.api.

 

Используется IdentityQueryService и application-сервисами перед публикацией событий.

 

Не передаёт доменный User и внутренние domain events за границу модуля Identity.

  UserResultMapper : Class

Преобразует доменный User в безопасный CurrentUserResult.

 

Mapper не изменяет User, не обращается к repository и не содержит бизнес-правила.
