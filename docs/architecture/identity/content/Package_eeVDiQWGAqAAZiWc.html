 persistence : Package

Содержит абстракции сохранения и поиска доменных объектов User, EmailVerification и внутреннего состояния refresh token.

Интерфейсы не содержат jOOQ records, SQL и деталей PostgreSQL.

 security : Package

Содержит абстракции хеширования паролей, генерации проверочных токенов, выпуска JWT и управления значениями refresh token.

Конкретные алгоритмы и библиотеки выбираются в infrastructure.

 messaging : Package

Содержит абстракции отправки проверочных писем и публикации публичных событий Identity.

Application определяет момент отправки сообщения, а infrastructure выполняет техническую доставку.

 TimeProvider : Class

Выходной порт получения текущего времени.

 

Используется при создании доменных объектов, проверке сроков действия, выпуске токенов и сохранении времени отзыва.

 

Позволяет тестировать сценарии без прямой зависимости от системных часов.
