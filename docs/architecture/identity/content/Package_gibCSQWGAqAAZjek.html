Name Description
 authentication : Package

Содержит преобразование проверенного JWT в стандартную модель аутентификации Spring Security.

 

Пакет извлекает userId и роли из claims, но не загружает User из базы данных при каждом HTTP-запросе.

 configuration : Package

Содержит конфигурацию Spring Security, JWT encoder, JWT decoder и параметры времени жизни токенов.

 

Ключевой материал поступает из внешней конфигурации и не хранится в исходном коде.

 token : Package

Содержит технические реализации выпуска access JWT, генерации refresh token и генерации одноразовых токенов подтверждения email.

 

Открытые refresh и verification tokens не сохраняются в базе данных.

 password : Package

Содержит техническую реализацию хеширования и проверки паролей.

 

Пакет скрывает конкретный алгоритм и параметры BCrypt от application и domain.
