 UserSummary : Class

Безопасное неизменяемое представление пользователя для межмодульного взаимодействия.

 

Содержит идентификатор, подтверждённый email, имя, фамилию, роли и состояние аккаунта.

 

Не содержит passwordHash, pendingEmail, JWT, refresh-токены, проверочные токены и persistence records.

 UserRoleView : Class

Публичное представление ролей пользователя.

 

Отделено от внутреннего доменного перечисления identity.domain.model.UserRole.

 

Один пользователь может одновременно иметь роли TEACHER и STUDENT.

 UserStatusView : Class

Публичное представление состояния аккаунта.

 

PENDING_EMAIL_VERIFICATION означает, что пользователь зарегистрирован, но ещё не подтвердил email.

 

ACTIVE означает, что пользователь подтвердил email и может проходить аутентификацию.

 

BLOCKED означает, что доступ пользователя заблокирован.
