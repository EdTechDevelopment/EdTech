Model Elements
Name Description
  ResendEmailVerificationRequest : Class

Входная HTTP-модель запроса повторной отправки письма подтверждения.

 

Передаёт email пользователя. Наличие или отсутствие пользователя

не должно влиять на публичный HTTP-ответ.

  ConfirmEmailRequest : Class

Входная HTTP-модель подтверждения email.

 

Передаёт одноразовый открытый токен, полученный пользователем в письме.

Проверка назначения, срока действия, хэша и одноразовости токена

выполняется application-сценарием.

  LoginRequest : Class

Входная HTTP-модель аутентификации пользователя по email и паролю.

 

Модель только передаёт введённые данные. Проверка пароля и состояния

аккаунта выполняется LoginUseCase.

  RegisterRequest : Class

Входная HTTP-модель регистрации пользователя.

 

Содержит email, открытый пароль, имя, фамилию и выбранные роли.

Открытый пароль существует только во время обработки запроса

и никогда не возвращается в ответе и не сохраняется как часть User.

 

Точный состав и ограничения полей определяются OpenAPI.
