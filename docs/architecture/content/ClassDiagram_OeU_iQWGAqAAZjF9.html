Model Elements
Name Description
  RefreshTokenHasher : Class

Выходной порт вычисления hash полученного refresh token.

 

Hash используется для поиска RefreshTokenState, поскольку открытое значение refresh token в базе данных не хранится.

  RefreshTokenIssuer : Class

Выходной порт выпуска refresh token.

 

При отсутствии familyId создаёт новую token family. При ротации выпускает токен в существующей family.

 

Возвращает открытое значение, hash, идентификаторы и срок действия токена.

  AccessTokenIssuer : Class

Выходной порт выпуска короткоживущего access JWT.

 

Получает идентификатор пользователя, его роли и время выпуска. Конкретный алгоритм подписи, набор claims и длительность токена определяются в infrastructure.

  VerificationTokenHasher : Class
  VerificationTokenGenerator : Class

Выходной порт генерации криптографически стойкого одноразового токена подтверждения email.

 

Возвращает открытое значение, которое передаётся получателю письма. Это значение не сохраняется в базе данных.

  PasswordHasher : Class

Выходной порт безопасного хеширования и проверки паролей.

 

Скрывает от application конкретный алгоритм и его параметры. Реализация может использовать BCrypt в infrastructure.
