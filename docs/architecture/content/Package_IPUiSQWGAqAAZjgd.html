 UserPersistenceMapper : Class

Преобразует UserPersistenceData в доменный aggregate User и обратно.

 

Восстанавливает Email, pendingEmail, PasswordHash, UserRole и UserStatus. Не выполняет SQL и не проверяет прикладные правила.

 

При сохранении создаёт отдельные записи CURRENT и PENDING для таблицы identity_user_emails.

 EmailVerificationPersistenceMapper : Class

Преобразует jOOQ record проверки email в aggregate EmailVerification и обратно.

 

Восстанавливает VerificationTokenHash, Email и VerificationPurpose. Не определяет срок действия и не изменяет состояние проверки.

 RefreshTokenPersistenceMapper : Class

Преобразует запись refresh token в RefreshTokenState и обратно.

 

Использует название toApplication, потому что RefreshTokenState принадлежит application.model и не является доменной сущностью.
