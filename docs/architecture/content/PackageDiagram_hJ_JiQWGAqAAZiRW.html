Model Elements
Name Description
  model : Package

Содержит внутренние модели application, необходимые для выпуска и хранения токенов.

Эти модели не передаются frontend и другим бизнес-модулям.

  exception : Package

Содержит ошибки прикладных сценариев Identity.

Эти исключения образуют стабильную границу между application и presentation. Application преобразует внутренние доменные ошибки в ошибки, понятные вызывающему слою.

  command : Package

Содержит неизменяемые входные модели операций, изменяющих состояние системы.

Command передаёт данные конкретного сценария и не содержит бизнес-логики, HTTP-аннотаций или persistence-моделей.

  query : Package

Содержит неизменяемые модели запросов, не изменяющих состояние Identity.

  port : Package

Содержит входные и выходные границы application.

Входные порты описывают сценарии, доступные presentation. Выходные порты описывают возможности, которые application требует от infrastructure.

  service : Package

Содержит реализации входных портов и публичного IdentityQuery.

Сервисы загружают доменные объекты, вызывают их методы, сохраняют изменения через output ports и преобразуют результат выполнения сценария.

  result : Package

Содержит результаты выполнения application-сценариев.

Result не является HTTP response и не является публичной моделью identity.api. Presentation преобразует result в REST response.

  mapper : Package

Содержит преобразования доменных объектов в application-results и публичные модели identity.api.

Mapper не обращается к repository, не меняет доменные объекты и не содержит бизнес-правила
