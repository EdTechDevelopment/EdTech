 IdentityTokenProperties : Class

Содержит конфигурационные параметры JWT, refresh token и verification token.

 

Связывается с application.yml через ConfigurationProperties и проверяет корректность значений при запуске.

 

Ключи подписи загружаются из внешнего источника и не хранятся в репозитории.

 JwtConfiguration : Class

Создаёт JwtEncoder и JwtDecoder для RS256.

 

JwtDecoder проверяет подпись, срок действия, issuer и audience. Конфигурация использует ключевой материал из внешнего источника.

 

Класс не выпускает токены и не содержит бизнес-правила.

 SecurityConfiguration : Class

Настраивает stateless Spring Security и проверку Bearer JWT через OAuth2 Resource Server.

 

Определяет публичные и защищённые endpoints, подключает IdentityJwtAuthenticationConverter, CORS, AuthenticationEntryPoint и AccessDeniedHandler.

 

SecurityConfiguration зависит только от стандартных интерфейсов обработчиков Spring Security и не импортирует конкретные классы presentation.
