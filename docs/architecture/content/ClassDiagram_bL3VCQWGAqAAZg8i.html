  TokenResponse : Class

HTTP-ответ успешной аутентификации или обновления токенов.

 

Содержит access JWT, тип авторизации Bearer и информацию о сроке

действия access token.

 

Refresh token в эту модель не входит и передаётся только через

HttpOnly cookie.

  VerificationPendingResponse : Class

HTTP-ответ успешной регистрации неподтверждённого пользователя.

 

Сообщает frontend, что аккаунт создан и ожидает подтверждения email.

Может содержать email и время окончания действия отправленного

проверочного токена.
