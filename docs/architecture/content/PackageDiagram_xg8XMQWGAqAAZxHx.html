Model Elements
Name Description
  infrastructure : Package

Технический слой модуля Identity.

 

Реализует output-порты application и связывает бизнес-код с PostgreSQL, jOOQ, BCrypt, Spring Security,JWT , SMTP и системным временем.

 

Infrastructure зависит от application и domain, поскольку реализует объявленные ими интерфейсы и преобразует сохранённые данные в доменные объекты.

  domain : Package

Центральная бизнес-модель модуля Identity.

 

Содержит сущности, value object, перечисления, бизнес-правила, допустимые изменения состояния, доменные события и доменные исключения.

 

Domain является чистым Java-кодом и не зависит от Spring, HTTP, jOOQ, PostgreSQL, SMTP и Spring Session.

  application : Package

Прикладной слой, реализующий конкретные пользовательские сценарии Identity.

 

Оркестрирует выполнение операций, задаёт транзакционные границы, вызывает доменную модель и обращается к внешним технологиям через output-порты.

 

Application определяет последовательность действий, но не содержит реализации PostgreSQL, jOOQ, BCrypt, SMTP или Spring Session.

  presentation : Package

Внешний HTTP-интерфейс модуля Identity для frontend.

 

Принимает HTTP-запросы и JSON, выполняет структурную валидацию входных данных, преобразует request DTO в application-команды, вызывает input-порты и формирует HTTP-ответы.

 

Также преобразует исключения application и domain в единый формат ApiError.

  api : Package

Публичный Java API модуля Identity для взаимодействия с другими backend-модулями.

 

Предоставляет безопасные сведения о пользователях: идентификатор, имя, фамилию, email, роли и статус аккаунта.

 

Tutoring и Scheduling обращаются к Identity только через этот пакет. Внутренние доменные сущности, пароль, сессии и проверочные токены через API не раскрываются.
