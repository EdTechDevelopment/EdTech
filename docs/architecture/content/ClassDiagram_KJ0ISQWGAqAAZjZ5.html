Model Elements
Name Description
  InvalidCredentialsException : Class

Переданные учётные данные не прошли проверку.

 

Одинаковое исключение используется для неизвестного email и неверного пароля, чтобы не раскрывать существование аккаунта.

  InvalidUseCaseInputException : Class

Application-команда или query содержат некорректные или неподдерживаемые данные.

 

Исключение используется для ошибок прикладной валидации, которые не относятся к формату HTTP-запроса и не являются нарушением состояния конкретного aggregate.

  UserNotFoundException : Class

Пользователь, необходимый для выполнения прикладного сценария, не найден.

 

Presentation преобразует исключение в соответствующий HTTP-ответ без раскрытия внутренних persistence-данных.

  EmailAlreadyExistsException : Class

Переданный email уже используется как основной или ожидающий подтверждения адрес другого пользователя.

 

Возникает при регистрации или запросе изменения email.

  InvalidVerificationTokenException : Class

Проверочный токен неизвестен, просрочен, уже использован или был инвалидирован.

 

Исключение не раскрывает точную причину недействительности токена.

  InvalidRefreshTokenException : Class

Refresh token неизвестен, просрочен, отозван или был повторно использован.

 

При обнаружении повторного использования application может дополнительно отозвать всю связанную token family.

  AccountOperationNotAllowedException : Class

Запрошенная операция запрещена текущим состоянием аккаунта.

 

Используется как application-представление нарушения доменного состояния, которое presentation может преобразовать в единый HTTP-ответ.

  EmailVerificationRequiredException : Class

Аутентификация пользователя запрещена, потому что основной email ещё не подтверждён.

 

Presentation преобразует исключение в стабильный код ошибки, понятный frontend.
