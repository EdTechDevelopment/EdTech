Model Elements
Name Description
  UserResponse : Class

 

HTTP-представление данных текущего пользователя: идентификатора, email, pendingEmail, имени, фамилии, ролей, статуса аккаунта и временных меток в пределах утверждённого API-контракта.

Не содержит секретные и внутренние данные безопасности.

  UpdateCurrentUserRequest : Class

Входная HTTP-модель частичного изменения текущего пользователя.

Запрос должен содержать минимум одно изменяемое поле. Изменение email запускает двухэтапный процесс через pendingEmail. Роли, пароль и статус аккаунта через этот запрос не изменяются.

Полный набор доступных полей определяется OpenAPI.

  UserPresentationMapper : Class

Преобразует UpdateCurrentUserRequest и идентификатор текущего пользователя в UpdateCurrentUserCommand.

 

Преобразует результат application-сценария в UserResponse. Не выполняет бизнес-проверки, не загружает User и не обращается к внешним системам.

 

Конкретный способ реализации преобразований выбирает разработчик.
