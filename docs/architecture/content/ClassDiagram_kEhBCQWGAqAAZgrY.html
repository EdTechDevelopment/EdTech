  cookie : Package

Содержит HTTP-логику передачи refresh token через cookie.

 

Пакет получает готовое значение refresh token от application и

создаёт безопасную HttpOnly cookie для браузера. При logout пакет

формирует cookie, удаляющую refresh token на стороне клиента.

 

Пакет не создаёт JWT, не проверяет его подпись, не выполняет ротацию,

не отзывает токен и не сохраняет refresh-сессию. Эти операции

выполняются application и infrastructure.

  mapper : Package

Содержит преобразования между HTTP-моделями auth и моделями application.

 

Mapper преобразует request DTO в application command и application

result в response DTO. Преобразование должно быть детерминированным

и не иметь внешних побочных эффектов.

 

Mapper не обращается к repository, базе данных, JWT-провайдеру,

SMTP и другим backend-модулям. Он не проверяет бизнес-правила

и не управляет транзакциями.

  model : Package

Объединяет HTTP-модели сценариев регистрации и аутентификации.

 

Модели этого пакета описывают данные, которыми обмениваются frontend

и backend. Они не являются доменными сущностями, application-командами

или структурами хранения данных.

 

Полный состав полей, обязательность, форматы и ограничения моделей

определяются OpenAPI-контрактом.

  controller : Package

Содержит REST-контроллеры сценариев регистрации и аутентификации.

 

Контроллеры определяют URL, HTTP-метод, ожидаемый request и возвращаемый

response. Они извлекают данные из JSON, заголовков и cookie, после чего

передают выполнение входному application-порту.

 

Контроллер может выбрать HTTP-статус, установить или удалить cookie

и передать результат mapper-классу.

 

Контроллер не должен содержать SQL, транзакции, бизнес-проверки,

криптографические операции, генерацию токенов или непосредственные

вызовы infrastructure.
