Внешний HTTP-интерфейс модуля Identity для frontend.

 

Принимает HTTP-запросы и JSON, выполняет структурную валидацию входных данных, преобразует request DTO в application-команды, вызывает input-порты и формирует HTTP-ответы.

 

Также преобразует исключения application и domain в единый формат ApiError.

 account : Package

Группа HTTP-сценариев работы с общими данными текущего аккаунта.

 

Пакет обслуживает изменение имени, фамилии и email пользователя.

Текущий пользователь определяется по подтверждённому access JWT,

а не по userId, переданному frontend.

 

Изменение имени и фамилии выполняется сразу. Изменение email запускает

процесс подтверждения нового адреса через pendingEmail.

 

TeacherProfile, StudentProfile, предметы и расписание не принадлежат

этому пакету.

 auth : Package

Группа HTTP-сценариев, связанных с регистрацией и аутентификацией

пользователя.

 

Пакет обслуживает регистрацию, подтверждение email, повторную отправку

письма подтверждения, вход, обновление токенов и выход.

 

Auth отвечает только за HTTP-представление этих сценариев. Он принимает

учётные данные и токены от клиента, передаёт их application use cases

и формирует соответствующий HTTP-ответ.

 

Пакет не сравнивает пароль с хэшем, не создаёт JWT, не проверяет

подпись JWT, не сохраняет refresh token и не загружает пользователя

из базы данных.
