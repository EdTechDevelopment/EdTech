Name Description
 RegisterUserService : Class

Реализация RegisterUserUseCase.

 

Проверяет входные данные и уникальность email, хеширует пароль, создаёт aggregate User и EmailVerification, сохраняет их и инициирует отправку проверочного письма.

 

После сохранения публикует UserRegisteredEvent и возвращает RegistrationResult. Сервис определяет порядок операций, а доменные инварианты выполняются объектами domain.

 GetCurrentUserService : Class

Реализация GetCurrentUserUseCase.

 

Загружает User по идентификатору текущего авторизованного пользователя и преобразует его в CurrentUserResult через UserResultMapper.

 

Сервис не принимает userId непосредственно от HTTP-клиента.

 UpdateCurrentUserService : Class

Реализация UpdateCurrentUserUseCase.

 

Загружает User и вызывает доменные операции изменения имени или запроса изменения email.

 

При изменении email проверяет его уникальность, создаёт EmailVerification с назначением EMAIL_CHANGE и инициирует отправку письма. После сохранения публикует UserAccountUpdatedEvent.

 IdentityQueryService : Class

Реализация публичного интерфейса identity.api.query.IdentityQuery.

 

Предоставляет другим бизнес-модулям безопасное чтение пользователей, пакетное чтение, поиск по email и проверку роли.

 

Преобразует доменный User в UserSummary и никогда не возвращает domain или persistence-модели за пределы Identity.
