  exception : Package

Содержит исключения, возникающие при нарушении инвариантов агрегата User и принадлежащих ему объектов-значений.

 

Исключения описывают доменную причину ошибки, но не содержат HTTP-статусы, API error codes, JSON-модели или сведения о persistence. Преобразование доменной ошибки в application-ошибку и HTTP-ответ выполняется во внешних слоях.

  event : Package
  model : Package

Содержит корень агрегата User, принадлежащие ему объекты-значения и перечисления. User является единственной точкой изменения состояния аккаунта и защищает его бизнес-инварианты.

 

Пакет не выполняет поиск уникального email, проверку открытого пароля, создание JWT, сохранение в базу данных или отправку писем. Эти действия координируются application-слоем через выходные порты.
