Name Description
  User : Class

Корень агрегата аккаунта пользователя. Хранит идентификатор, текущий и ожидающий подтверждения email, хэш пароля, имя, фамилию, роли, статус и временные метки.

 

User является единственной точкой изменения состояния аккаунта. Он проверяет наличие хотя бы одной роли, запрещает недопустимые переходы статуса, управляет двухэтапной сменой email и не позволяет аутентификацию до подтверждения адреса.

 

Класс не хранит открытый пароль, JWT, refresh token или технические данные persistence. Уникальность email проверяется application-сервисом через UserRepository.

  InvalidUserStateException : Class

Возникает, когда операция над User недопустима в текущем состоянии аккаунта. Например, при повторной активации уже активного пользователя или подтверждении email, который не совпадает с pendingEmail.

 

Исключение отражает нарушение правила перехода состояния внутри агрегата.

  EmailNotVerifiedException : Class

Возникает при попытке аутентификации пользователя, первоначальный email которого ещё не подтверждён.

 

Application-слой преобразует это исключение в ошибку EMAIL_NOT_VERIFIED. Само исключение не содержит HTTP-статус или API error code.

  InvalidUserDataException : Class

Возникает при создании или изменении User с данными, нарушающими основные инварианты агрегата. Например, при отсутствии имени, фамилии или хотя бы одной роли.

 

Исключение не содержит сведений о HTTP и не выполняет транспортную валидацию request-моделей.

  InvalidEmailexception : Class

Возникает при попытке создать объект Email из пустого, некорректного или недопустимого значения.

 

Исключение не используется для ситуации, когда корректный email уже занят другим пользователем. Проверка уникальности выполняется application-сервисом через UserRepository.
