# Scheduling

Scheduling владеет уроками, участниками, интервалами, пересечениями, статусами, отменами и статистикой уроков. Связь преподаватель–ученик принадлежит Tutoring; Scheduling проверяет её через публичный API, не читая таблицы Tutoring. Общая граница описана в [архитектуре backend](../BACKEND_ARCHITECTURE.md).

При отвязке ученика нужен совместимый guard для этой пары: создание урока и `UnlinkStudentWorkflow` должны брать одну и ту же блокировку. Политика обработки будущих уроков и запросов изложена в [сценариях Application Tutoring](../tutoring/TUTORING_APPLICATION_SCENARIOS.md). Отдельная полная спецификация внутреннего устройства Scheduling в этом каталоге пока не утверждена.
