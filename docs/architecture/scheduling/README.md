# Scheduling

Scheduling владеет уроками, участниками, временем, статусами, отменами, запросами на урок и статистикой. Связь преподаватель–ученик принадлежит Tutoring и проверяется через его публичный API.

На 2026-10-13 модуль ещё проектируется и содержит только package-info.java. Пользователь утвердил завершение MVP Tutoring без Scheduling. UnlinkStudentWorkflow, HTTP-отвязка и составная карточка со статистикой отложены.

При будущей интеграции создание урока и отвязка должны получать одну транзакционную блокировку конкретной пары. Перед удалением связи Scheduling отменяет будущие уроки, отклоняет незавершённые запросы и сохраняет историю. Политика описана в [сценариях Tutoring](../tutoring/TUTORING_APPLICATION_SCENARIOS.md); полноценная спецификация внутреннего устройства ещё требует проектирования.

Публичный активный профиль показывает возраст и указанные контакты без подтверждения контактного email. Точная дата рождения доступна только владельцу в account-данных /me. Публичность профиля не открывает чужие уроки, календарь или статистику.
