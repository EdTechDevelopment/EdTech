## Правило чтения

Более поздние согласованные решения уточняют ранние этапы. Ученик может не выбирать предметы. Дата рождения хранится только в Identity и видна владельцу в данных аккаунта; активный учебный профиль публично показывает вычисленный возраст, указанный контактный email и обычные поля без связи. Контактный email профиля не требует подтверждения.

Проектирование Tutoring завершено на уровне этих спецификаций. Для реализации потребуются изменения контрактов Identity и Notifications, Scheduling guard для отвязки, общие транзакционные workflows, миграции и тесты. Подробный перечень зависимостей и критериев завершения приведён в итоговой архитектуре.
