# Notifications

Notifications владеет очередью доставки, SMTP, шаблонами писем, попытками отправки и техническим статусом доставки. Бизнес-решение о необходимости письма принимает вызывающий модуль. Общая граница зафиксирована в [архитектуре backend](../BACKEND_ARCHITECTURE.md).

Для Tutoring нужны отдельные заявки на подтверждение профильной почты и приглашение ученика, `dedup key`, атомарная постановка заявки в общую транзакцию и отправка после commit. Конкретные требования описаны в [итоговой архитектуре Tutoring](../tutoring/TUTORING_ARCHITECTURE.md). Отдельная полная спецификация внутреннего устройства Notifications в этом каталоге пока не утверждена.
