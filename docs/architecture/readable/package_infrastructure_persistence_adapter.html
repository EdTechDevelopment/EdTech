Назначение пакета

Содержит адаптеры, реализующие persistence output ports application.

Адаптер координирует mapper и низкоуровневый jOOQ repository. SQL непосредственно внутри адаптера не размещается.

JooqEmailVerificationRepositoryAdapter
Класс
Реализация application-порта EmailVerificationRepository через jOOQ. Преобразует доменные параметры в технические значения, вызывает EmailVerificationJooqRepository и восстанавливает aggregate через EmailVerificationPersistenceMapper. Поиск токена для подтверждения выполняется с блокировкой строки.

JooqRefreshTokenRepositoryAdapter
Класс
Реализация application-порта RefreshTokenRepository через jOOQ. Использует RefreshTokenJooqRepository для SQL-операций и RefreshTokenPersistenceMapper для преобразования записей. Поиск refresh token выполняется с блокировкой строки, чтобы обеспечить атомарную ротацию.

◇
JooqUserRepositoryAdapter
Класс
Реализация application-порта UserRepository через jOOQ. Передаёт SQL-операции UserJooqRepository и использует UserPersistenceMapper для преобразования данных. При нарушении уникальности email преобразует техническую ошибку PostgreSQL в EmailAlreadyExistsException.
