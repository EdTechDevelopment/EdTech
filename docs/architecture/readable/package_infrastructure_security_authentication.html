Назначение пакета

Содержит преобразование проверенного JWT в стандартную модель аутентификации Spring Security.

Пакет извлекает userId и роли из claims, но не загружает User из базы данных при каждом HTTP-запросе.

IdentityJwtAuthenticationConverter
Класс
Преобразует проверенный Spring Security Jwt в стандартный JwtAuthenticationToken. Использует claim sub как идентификатор пользователя и преобразует значения roles в GrantedAuthority. Не обращается к UserRepository и не загружает пользователя из базы данных при каждом запросе.
