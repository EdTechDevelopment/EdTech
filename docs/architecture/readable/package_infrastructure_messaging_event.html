SpringIntegrationEventPublisher
Класс
Публикует публичные события Identity через Spring ApplicationEventPublisher. Получает только события из identity.api.event. Внутренние domain events перед публикацией преобразуются IdentityApiMapper. Подписчики других модулей обрабатывают события после успешной фиксации транзакции.
