UserPersistenceData
Класс
Внутренняя составная модель загруженного пользователя. Объединяет основную запись пользователя, его текущий и ожидающий подтверждения email, а также набор ролей. Используется между UserJooqRepository и UserPersistenceMapper. Не передаётся в application, domain, presentation или public API.
