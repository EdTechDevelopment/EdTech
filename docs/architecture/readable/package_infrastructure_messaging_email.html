Назначение пакета

Содержит адаптер передачи проверочных писем публичному API модуля Notifications.

Identity определяет получателя, назначение и срок действия проверки. Notifications сохраняет запрос и выполняет техническую SMTP-доставку.

NotificationVerificationEmailAdapter
Класс
Преобразует запрос Identity в типизированную команду публичного API модуля Notifications. Формирует confirmationUrl, преобразует VerificationPurpose во внешний VerificationEmailPurpose и вызывает NotificationGateway.enqueue. Адаптер не использует SMTP, JavaMailSender и внутренние пакеты Notifications.
