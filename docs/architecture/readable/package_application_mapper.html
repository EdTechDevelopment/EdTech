IdentityApiMapper
Класс
Преобразует внутренние доменные объекты и domain events в публичные модели identity.api. Используется IdentityQueryService и application-сервисами перед публикацией событий. Не передаёт доменный User и внутренние domain events за границу модуля Identity.
