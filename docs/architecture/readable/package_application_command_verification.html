ConfirmEmailCommand
Класс
Неизменяемая входная модель подтверждения email. Содержит открытое значение одноразового проверочного токена. Application вычисляет его hash и выполняет поиск EmailVerification по полученному hash. Открытое значение токена не сохраняется.

ResendEmailVerificationCommand
Класс
Неизменяемая входная модель запроса повторного письма подтверждения. Ответ сценария не должен позволять определить, зарегистрирован ли переданный email. В Java может быть реализована как record.
