Исходная спецификация VP

Назначение пакета

Фиксирует факт успешного создания агрегата User. В момент возникновения пользователь имеет статус PENDING_EMAIL_VERIFICATION и ещё не может выполнять вход.

Событие является внутренним для домена. Application-слой может преобразовать его в публичный UserRegisteredEvent и использовать для запуска разрешённых межмодульных сценариев.

UserAccountUpdatedEvent
Класс
Фиксирует факт успешного изменения данных аккаунта пользователя. Может возникать после изменения имени, фамилии или завершённой смены подтверждённого email. Событие не содержит пароль, passwordHash, pendingEmail или данные токенов. Application-слой получает необходимый безопасный снимок User и преобразует событие в публичный UserAccountUpdatedEvent.

UserActivatedDomainEvent
Класс
Фиксирует факт активации аккаунта после успешного подтверждения первоначального email. Событие создаётся только после допустимого перехода пользователя из состояния PENDING_EMAIL_VERIFICATION в ACTIVE. Application-слой может преобразовать событие в публичный UserActivatedEvent.

UserRegisteredDomainEvent
Класс
Фиксирует факт успешного создания агрегата User. В момент возникновения пользователь имеет статус PENDING_EMAIL_VERIFICATION и ещё не может выполнять вход. Событие является внутренним для домена. Application-слой может преобразовать его в публичный UserRegisteredEvent и использовать для запуска разрешённых межмодульных сценариев.
