Исходная спецификация VP

Назначение пакета

Содержит преобразования HTTP-моделей account в модели application и обратно.

Mapper добавляет в application-команду userId, полученный контроллером из подтверждённого JWT, и переносит изменяемые данные из request.

Пакет не выполняет проверку уникальности email, не загружает User и не применяет к нему изменения.

Преобразует UpdateCurrentUserRequest и идентификатор текущего пользователя в UpdateCurrentUserCommand. Преобразует результат application-сценария в UserResponse.
