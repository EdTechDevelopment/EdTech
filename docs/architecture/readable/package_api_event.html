Назначение пакета

Публичное событие регистрации пользователя.

Публикуется после успешного сохранения нового аккаунта.

Tutoring обрабатывает событие, чтобы найти ожидающее приглашение по email и связать его с зарегистрированным userId. Приглашение остаётся в статусе PENDING до явного принятия учеником.
