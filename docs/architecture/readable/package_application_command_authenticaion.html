LoginCommand
Класс
Неизменяемая входная модель аутентификации пользователя. Содержит email и открытый пароль. Открытый пароль используется только для проверки через PasswordHasher и нигде не сохраняется.

Неизменяемая входная модель выхода пользователя. Содержит открытое значение refresh token, который application должен найти по hash и отозвать.

RefreshTokenCommand
Класс
Неизменяемая входная модель обновления токенов. Содержит открытое значение refresh token, полученное presentation из HttpOnly cookie. Application вычисляет hash токена и не сохраняет его открытое значение.
