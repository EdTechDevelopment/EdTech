Назначение пакета

Публичный синхронный интерфейс чтения данных пользователей.

Используется модулями Tutoring и Scheduling для получения безопасного представления пользователя и проверки его ролей.

Интерфейс не изменяет состояние Identity и не возвращает внутренние доменные сущности.
