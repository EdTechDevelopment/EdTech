Содержит REST-контроллеры операций текущего аккаунта.

Контроллер получает идентификатор текущего пользователя из контекста

Spring Security, преобразует HTTP-запрос в application-команду

и вызывает входной application-порт.

Контроллер не должен принимать идентификатор изменяемого пользователя

из request body или path parameter.

CurrentUserController
Класс
HTTP-точка входа для изменения общих данных текущего пользователя. Получает userId из claim sub подтверждённого access JWT. Принимает изменение имени, фамилии или email и передаёт его UpdateCurrentUserUseCase. Контроллер не изменяет User самостоятельно и не решает, можно ли использовать новый email.
