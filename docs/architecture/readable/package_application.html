identity.application
Исходная спецификация VP

Назначение пакета

Прикладной слой, реализующий конкретные пользовательские сценарии Identity.

Оркестрирует выполнение операций, задаёт транзакционные границы, вызывает доменную модель и обращается к внешним технологиям через output-порты.

Application определяет последовательность действий, но не содержит реализации PostgreSQL, jOOQ, BCrypt, SMTP или Spring Session.
