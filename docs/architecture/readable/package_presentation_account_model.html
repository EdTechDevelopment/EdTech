Исходная спецификация VP

Назначение пакета

Объединяет HTTP-модели операций текущего аккаунта.

Модели этого пакета описывают обмен данными между frontend и Identity.

Они не являются доменной сущностью User и не должны использоваться

как persistence-модели.

request
identity.presentation.account.model.request
Содержит входные HTTP-модели изменения текущего аккаунта. Request содержит только поля, которые пользователь имеет право изменять через соответствующий endpoint. Идентификатор пользователя, роли, статус аккаунта и технические поля не принимаются от frontend. Полный состав полей и правила структурной валидации определяются OpenAPI-контрактом.

identity.presentation.account.model.response
Содержит HTTP-представление данных аккаунта пользователя. Response-модели предназначены для frontend и содержат только разрешённые данные. В них отсутствуют пароль, passwordHash, открытые проверочные токены, refresh token и внутренние сведения безопасности.
