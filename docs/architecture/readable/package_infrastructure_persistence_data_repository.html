Назначение пакета

Содержит низкоуровневые компоненты доступа к PostgreSQL через DSLContext.

Repository выполняет SQL и возвращает jOOQ records или persistence data. Он не зависит от domain и не реализует application output ports.

EmailVerificationJooqRepository
Класс
Выполняет SQL-операции с проверками email через DSLContext. Поиск по token hash при подтверждении получает блокировку строки FOR UPDATE. Это предотвращает одновременное использование одноразового токена двумя запросами. Repository не зависит от EmailVerification и других domain-классов.
›
◇
RefreshTokenJooqRepository
Класс
Выполняет SQL-операции с состоянием refresh token через DSLContext. Поиск токена для refresh получает блокировку строки FOR UPDATE. Это предотвращает успешную параллельную ротацию одного refresh token. Методы изменения возвращают количество затронутых строк для технической проверки результата.
›
◇
UserJooqRepository
Класс
Низкоуровневый компонент SQL-доступа к пользователям, email и ролям через DSLContext. Возвращает только jOOQ records и UserPersistenceData. Не создаёт доменный User и не зависит от domain. Операции сохранения пользователя, email и ролей выполняются в транзакции application-сервиса.
