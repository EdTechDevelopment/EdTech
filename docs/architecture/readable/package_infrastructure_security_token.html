token

identity.infrastructure.security.token
Исходная спецификация VP

Назначение пакета

Содержит технические реализации выпуска access JWT, генерации refresh token и генерации одноразовых токенов подтверждения email.

Открытые refresh и verification tokens не сохраняются в базе данных.

SecureRefreshTokenIssuer
Класс
Генерирует криптографически стойкий URL-safe refresh token через SecureRandom. При отсутствии familyId создаёт новую token family. При ротации сохраняет существующую familyId. Возвращает открытое значение, SHA-256 hash, идентификаторы и срок действия токена.

◇
SecureVerificationTokenGenerator
Класс
Генерирует криптографически стойкий одноразовый токен подтверждения email. Использует SecureRandom и URL-safe Base64 без padding. Открытое значение передаётся только в ссылку подтверждения.
›
◇
Sha256RefreshTokenHasher
Класс
Вычисляет SHA-256 hash полученного refresh token. Hash используется для поиска сохранённого RefreshTokenState. Открытое значение токена в PostgreSQL не хранится.
›
◇
Sha256VerificationTokenHasher
Класс
Вычисляет SHA-256 hash одноразового токена подтверждения email. Возвращает доменный value object VerificationTokenHash. Открытое значение токена не сохраняется.
›
◇
SpringJwtAccessTokenIssuer
Класс
Выпускает короткоживущий access JWT через Spring Security JwtEncoder. JWT содержит sub, roles, iss, aud, iat и exp. Email в JWT не включается, потому что он может измениться. Токен подписывается RS256. Приватный ключ поступает из внешней конфигурации.
